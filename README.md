# Software-Development-Life-Cycle
How do I interpret user needs and implement them into a program? How does creating “user stories” help with this?
I interpret user needs and implement them into a program by reviewing all functional and non-functional requirements. This ensures that the program is readable for programmers and usable for customers. Creating "user stories" helps with this because it allows me to break down the project into smaller pieces through the perspective of the end-user. This allows me to create features and components before adding it together to make the final product. This ensures that each piece is fully functional, meets all requirements and aligns with the goal for the project. 

How do I approach developing programs? What Agile processes do I hope to incorporate into my future development work?
I approach developing programs by breaking it down into smaller components, continuous testing, and implementing review and feedback. Some of the agile processes that I hope to incorporate into future development work is Sprint Planning, Incremental Delivery and Sprint Retrospectives. This will allow me to continuously improve my programming, organization and communication skills. 

What does it mean to be a good team member in software development?
To be a good team member in software development you need to responsible for your role, be an active and efficient participant in team events. There also needs to be able to communicate effectively, be clear and well-organized and be able to receive and apply feedback. To be a good team member you should also be willing to constantly learn, adapt and improve.
